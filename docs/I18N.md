# Sistema i18n

## Idiomas

| Código | Idioma | Fichero |
|---|---|---|
| `es` | Español (referencia) | `i18n/es.json` |
| `en` | English | `i18n/en.json` |
| `pt` | Português | `i18n/pt.json` |
| `zh` | 中文 (chino simplificado) | `i18n/zh.json` |
| `hi` | हिन्दी (hindi) | `i18n/hi.json` |

- `DEFAULT_LANG = "es"` (`assets/js/config.js`). El idioma se guarda en `localStorage`.
- **Paridad total**: las 5 claves deben existir en los 5 ficheros (lo verifica `validate.js`).

## Reglas

1. Toda clave se define primero en `es.json` y se propaga a los otros 4 (traducción real, no copia del inglés en `zh`/`hi`).
2. Nombres: `seccion.camelCase` — nunca texto visible como clave.
3. **Nunca texto visible hardcodeado**:
   - JS: `t("clave")` (con interpolación: `t("footer.rights", { year })` → reemplaza `{year}`).
   - HTML estático: `data-i18n="clave"` (textContent) y `data-i18n-title="clave"` (title + aria-label).
4. Texto dinámico construido en código debe escaparse con `esc()` antes de inyectarse al DOM.

## Prefijos dinámicos

Generados en tiempo de ejecución; `validate.js` exige que existan completos en `es.json`:

- `phase.<fase>` — fases de partidos
- `notes.<nota>` — apuntes (`aet`, `pen`, `replay`...)
- `scorers.scope.<scope>` — `final` | `all`

## Países — `i18n/countries.json`

Separado de los idiomas. Clave = **código FIFA de 3 letras** + entidades históricas:

```json
{
  "BRA": { "es": "Brasil", "en": "Brazil", "pt": "Brasil", "zh": "巴西", "hi": "ब्राज़ील" },
  "TCH": { "es": "Checoslovaquia", "en": "Czechoslovakia", ... }
}
```

- Se traducen solo en competiciones de selecciones (`teamMode: "country"`).
- En clubes (`teamMode: "club"`) el nombre se muestra tal cual.
- API en `i18n.js`: `country(code)` → nombre en el idioma activo; `countryMatches(text)` → códigos que coinciden (para el buscador, multi-idioma).

## Flujo para añadir una clave

1. Añadir a `i18n/es.json`.
2. Propagar a `en`, `pt`, `zh`, `hi`.
3. Usar `t("clave")` o `data-i18n`.
4. `node scripts/validate.js` → 0 errores.

Usar la skill `deporte-i18n-sync` para no olvidar pasos.
